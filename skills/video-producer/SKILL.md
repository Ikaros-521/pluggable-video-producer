# 智能视频创作技能 (Video Producer Skill)

本技能赋予 Agent 专业的视频剪辑与二次创作能力。核心架构采用**“微内核流水线 + 槽位插件化”**设计：基础流水线确保音画同步与渲染稳定，风格插件（Plugins）负责注入垂直领域的文风、人声音色与视觉滤镜。

---

## 🧭 Agent 交互与执行 SOP

当用户提出视频创作、剪辑或解说需求时，Agent 应严格遵循以下步骤：

### 步骤 1：明确素材与创作意图
1. 确认用户提供的源视频路径（如 `"F:\【视频】\《后室》预告片，深度解读.mp4"`）或要求生成的视频主题。
2. 识别用户期望的风格调性（例如：想要做成悬疑惊悚的微短剧，还是快节奏的科普解说）。

### 步骤 2：动态发现与挂载插件
Agent 扫描本技能目录下的 `plugins/` 文件夹：
* **`plugin_analog_horror.md`**：适合诡异、惊悚、沉浸式心理恐怖题材。使用深沉低语人声（`zh-CN-YunjianNeural`，-8% 语速）与 VHS 录像带冷黄绿复古暗角。
* **`plugin_scp_archive.md`**：适合高能、快节奏、机密档案解说题材。使用极速激情科技男声（`zh-CN-YunxiNeural`，+18% 语速）与高对比度冷光锐化。

> 💡 **若用户需要全新的独特风格**：
> Agent 可直接指导用户，或由 Agent 协助在 `plugins/` 目录下新建一个 `plugin_<style>.md` 纯文本文件，填入发音人与提示词，即插即用！

### 步骤 3：智能生成旁白台词
Agent 结合插件中的【风格规约】与【Few-Shot 范例】，针对用户素材自主构思出高水准的旁白解说词（避免传统 AI 的假大空与陈词滥调）。

### 步骤 4：自主调度底层合成工具
Agent 通过静默执行脚本工具完成物理合成：
```bash
python skills/video-producer/scripts/producer_runner.py \
  --source "<源视频路径>" \
  --plugin "<目标插件路径>" \
  --output "output/output_<style>.mp4"
```
* 底层工具将自动调用 `edge-tts` 录制高清人声，并调用 `ffmpeg` 完成毫秒级切片与滤镜渲染。

### 步骤 5：结果交付与多风格对比呈现
1. 向用户汇报产出视频的存放路径与时长。
2. 简述该版本所应用的视听特色（音色、滤镜、叙事切入点）。
3. 主动询问用户是否需要尝试挂载其他插件生成另一种风格的对比版本。
